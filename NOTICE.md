## Game data

Achievement names, tiers and categories are factual game information compiled from [The Games Wiki](https://thegameswiki.com/nte/wiki/achievements) (August 2026); the requirement texts are this project's own summaries.

Character names, elements, roles, ranks and reaction rules are factual information compiled from publicly available community resources and in-game observation. No game files have been extracted, decompiled or redistributed. Console grid layouts, module shapes, Cartridge set shape requirements and character module bonuses are factual game information as published by the [Icy Veins NTE Console Tool](https://www.icy-veins.com/neverness-to-everness/console-tool); the planner itself is this project's own code. Recommended endgame stats, Cartridge stat priorities and recommended Cartridge sets are factual build guidance as published in community character build guides (October 2026).

## Reading codes from images

Team and build images saved from the site carry their code inside the PNG file and in a QR code (`NTE:` + a team code, `NTEC:` + a console code; the text a phone camera gives can be pasted into the site). "Read a code from an image" reads the file's note first, then the QR code, on the device: pictures aren't uploaded or saved.
